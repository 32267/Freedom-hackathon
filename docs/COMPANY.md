# Контекст компании (из презентации организаторов)

Для промпта и формулировок UI. Источник — презентация Freedom Holding Corp. (PDF, в git не кладём).

- **Freedom Broker / Freedom Инвестиции** — инвестиционная компания, биржевой брокер с доступом к рынкам США, Европы и СНГ.
- Входит в **Freedom Holding Corp.** (штаб-квартира в Алматы; акции на NASDAQ, тикер FRHC; регулятор — SEC).
- ~874 тыс. брокерских счетов. Клиенты — в Казахстане, Европе, США → отсюда RU / KZ / EN.
- Темы чатов (наше предположение — сверить с DEV): вывод/пополнение, тарифы и комиссии, сделки, доступ к счёту.
  Защищённые действия (данные счёта, операции) требуют **идентификации** — критерий 03.
- Ценности бренда: единые стандарты обслуживания во всех странах — один чек-лист на все языки.
