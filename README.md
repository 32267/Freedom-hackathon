# CQA — контроль качества диалогов Freedom Broker

Система оценивает работу оператора в чатах и звонках по чек-листу Freedom Broker (RU · KZ · EN),
объясняет каждую оценку цитатами из разговора, поддерживает апелляции и помогает продолжить работу
с клиентом при повторном обращении.

## Что умеет

| | |
|---|---|
| **Оценка** | 8 критериев чек-листа, веса, шкалы, N/A с перераспределением веса, округление до 2 знаков. Грубые ошибки — отдельным флагом |
| **Доказательность** | По каждому критерию — обоснование (RU/KZ/EN) и цитата; цитаты сверяются с транскриптом, выдуманные отбрасываются. Пропущенное действие — с проверенным участком разговора |
| **Надёжность** | Несколько независимых ответов модели и голосование по каждому критерию; расхождения уходят на проверку человеку |
| **Карточка диалога** | Транскрипт с ролями, переход по цитате к реплике, запись звонка с перемоткой на нужный момент |
| **Апелляция** | «⚖ Подать апелляцию» → очередь проверяющего (спорная оценка, комментарий, фрагмент) → решение с причиной → пересчёт; видно «было → стало» |
| **Чек-лист** | Редактор: добавить, заменить, изменить критерий, вес, шкалу, N/A; новая версия применяется к диалогам без правки кода |
| **Повторное обращение** | Сводка разговора: с чем обращался клиент, что сделано, что осталось, следующий шаг. При новом обращении клиента оператор видит историю |
| **Рейтинг операторов** | Средний балл, грубые ошибки, открытые вопросы по каждому оператору |
| **Данные** | Импорт набора организаторов по `group_id`, загрузка JSON и записей звонков (MP3/WAV — расшифровка Whisper), пакетная оценка с прогрессом |
| **Интерфейс** | HTML/CSS/JS на Web Components без сборки — каждый экран встраивается в Dynamics 365 как HTML-ресурс |

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # CQA_API_URL — адрес API организаторов; TEAM_NAME
uvicorn backend.main:app --port 8000
```
Открыть http://localhost:8000. При первом запуске база сама подхватывает чек-лист и диалоги из `data/DEV.json`
(или импорт кнопкой «Диалоги → Импорт набора»). Без модели и затрат: `SCORING_MODE=mock`.
Публичная ссылка для жюри: `scripts/tunnel.sh` (Cloudflare, вход по паролю из `CQA_BASIC_AUTH`).

**Модель:** Claude (`claude-haiku-5-5`) через Claude Code, 3 ответа на диалог с голосованием; резерв — Codex
или Claude API (`LLM_PROVIDERS` в `.env`). Стоимость одной оценки по прайсу API ≈ $0.02–0.05.

## Контрольный набор (10 чатов)

```bash
curl -X POST localhost:8000/api/datasets/<group_id>/import
curl -X POST localhost:8000/api/evaluations/batch -H 'Content-Type: application/json' -d '{"group_id": "<group_id>", "providers": "claude_cli", "samples": 3}'
curl localhost:8000/api/jobs/<job_id>                        # ждём "status": "done"
python tools/export_results.py --set prod --group <group_id> # → results/prod/results.json (проверка формата)
python tools/readme_results.py                               # обновить таблицу «Результаты» в README
git add results README.md && git commit -m "results: prod" && git push
```
Если на контроле заменят критерий: «Чек-лист» → «＋ Критерий» → «вместо какого» → сохранить → применить к диалогам → повторить экспорт.
